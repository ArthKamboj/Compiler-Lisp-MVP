# Micro-Lisp Compiler & Virtual Machine

A lightweight, stack-based Lisp compiler and virtual machine written from scratch in modern C++17.

This project demonstrates the complete lifecycle of a programming language front-end and back-end: taking raw string input, building a type-safe Abstract Syntax Tree (AST), compiling it down to linear bytecode, and executing it on a custom stack-based virtual machine.

## Architecture

The project is broken down into five distinct phases of execution, ensuring a clean separation of concerns between syntax parsing, memory state, translation, and execution.

### 1. The Lexer (`lexer.h`, `lexer.cpp`)
The lexer (or scanner) is the first stage of the pipeline. It takes a raw string of Lisp code, such as `(+ 10 (* 2 5))`, and breaks it into an array of distinct, manageable text tokens. It does this by padding structural characters like parentheses with whitespace, allowing standard string-stream parsing to extract keywords, symbols, and primitive values.

### 2. The Parser and AST (`parser.h`, `parser.cpp`, `types.h`)
The parser consumes the tokens generated by the lexer and builds a hierarchical Abstract Syntax Tree (AST).

- **`types.h`** defines the `LispVal` struct, which uses modern C++17 `std::variant` to act as a memory-safe recursive union. A `LispVal` can hold a `double`, `bool`, `std::string` (symbol), or a `std::vector` of `LispVal`s (a list).
- **`parser.cpp`** implements a recursive descent parser. It reads tokens from left to right, dynamically building nested `LispVal` nodes whenever it encounters an open parenthesis, and returning the completed tree when it reaches the matching close parenthesis.

### 3. The Environment (`environment.h`)
The environment is the memory structure responsible for variable binding and lexical scoping. It is implemented as a class wrapping a `std::unordered_map` that maps string symbols to `LispVal`s.

Each environment holds a `std::shared_ptr` to an outer (parent) environment. If the VM attempts to fetch a variable that does not exist in the local scope, the environment recursively searches up the parent chain until it finds the global scope.

### 4. The Bytecode Compiler (`compiler.h`, `compiler.cpp`)
The compiler bridges the front end (AST) and the back end (VM). It does not execute the code directly; instead, its job is strict translation. It recursively traverses the AST and flattens it into a 1D array of machine instructions (bytecode).

- It translates math operations into Reverse Polish Notation (postfix) operations such as `PUSH`, `PUSH`, `ADD`.
- It translates variable lookups and definitions into `GET_GLOBAL` and `SET_GLOBAL` opcodes.

### 5. The Virtual Machine (`vm.h`, `vm.cpp`)
The Virtual Machine (VM) is the execution engine. It maintains a runtime stack (`std::vector<LispVal>`) and holds a reference to the active `Environment`.

It loops through the compiler-generated bytecode instruction by instruction:

- **CONST**: pushes a primitive value onto the stack.
- **Math (`ADD`, `SUB`, `MUL`, `DIV`)**: pops the top two values off the stack, performs the calculation, and pushes the result back.
- **State (`GET_GLOBAL`, `SET_GLOBAL`)**: interacts with the `Environment` to persist or retrieve stored variables.

## Build Instructions

This project requires a C++ compiler with C++17 support, such as GCC 7+, Clang 5+, or MSVC 19.14+.

To compile the project from the terminal, link all `.cpp` files together:

```bash
g++ -std=c++17 main.cpp lexer.cpp parser.cpp compiler.cpp vm.cpp -o lisp_compiler
```

## Usage

Run the compiled executable:

- **Linux/macOS:** `./lisp_compiler`
- **Windows:** `lisp_compiler.exe`

## Example Execution

The `main.cpp` file contains a test pipeline that sequentially executes Lisp commands, persisting the state of the variables across evaluations.

### Lisp
```lisp
(define radius 5)
(define pi 3.14159)
(* pi (* radius radius))
```

### Expected Output
```plaintext
Executing: (define radius 5)
----RESULT----
5
--------------
Executing: (define pi 3.14159)
----RESULT----
3.14159
--------------
Executing: (* pi (* radius radius))
----RESULT----
78.5397
--------------
```
